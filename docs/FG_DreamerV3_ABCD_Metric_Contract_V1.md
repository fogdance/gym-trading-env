# FG ABC 评估指标合同 V1

适用：开发验证的完整真实主力合约。固定初始本金 300000，引用统一方向和成本配置，不改变 Env Reward。

## 主指标与失败

`reward_per_day = total_reward / eligible_trading_days`。分母来自完整验证行情中人工方向有效的交易日，包含主动 WAIT 与满仓日期；另列 `raw_trading_days`。无有效方向日时主指标为空，不用 0 替代。

完整三手止盈实际模拟成交才进入 `reward_events`，逐笔与 `60/(60+elapsed_minutes)` 对账，entry_id 不重复。交易状态：有完整 TP Reward 为 success；已完成其他退出为 terminal_failure；截至评价终点仍未完成为 right_censored。未完成部分止盈不得冒充完整批次成功。

自然时间包括夜间、周末与休市；交易 bar 数仅统计开仓所属执行 bar 至退出 bar。开仓 bob 可能等于上一根 eob，**不得因此将上一根信号 bar 的价格放入持仓路径**。逐笔 MAE 使用实际入场所属 bar 起的逆向 OHLC 极值，标记为保守上界；无法从分钟数据证明 TP 后的极值是否早于退出，不能把它称作逐 tick 真实 MAE。

5/15/60 自然分钟和 1/5 个交易日分别输出成功数、可观察数、删失数及比例。交易日 horizon 到对应交易日末尾；期末观察不足且交易未完成的样本不混作失败。完整终局失败仍纳入失败，不因等待时间短而剔除。

## 账户与动作

- 最大浮亏：现有 Env 的组合 MTM 最坏浮亏。
- 最大权益回撤：完整 intrabar 与 close 权益样本的历史峰值减当时权益。
- 净收益：期末权益减 300000，包含费用与未平仓 MTM；另列现有账簿已实现损益与手续费。
- 满仓比例：推进前 6 手占用分钟 / 方向有效且可观察的执行分钟，不把休市自然时间当可交易分钟。
- ADD_request 与 ADD_fill 分别记录请求动作与真实开仓批次；WAIT_voluntary 为 ADD 合法时 WAIT，WAIT_masked 为 ADD 不合法时 WAIT。
- 主力退出日按旧合约成交，未退出的仓位仍保留并报告；不使用新合约价格。

## 随机诊断

独立 Random ADD 固定 p=0.5，Always/Rule/Random/Dreamer 均运行独立闭环账户。

Matched random 条件于 Dreamer 成交轨迹，按交易日、人工方向、日夜盘和下一开盘的 60 分钟桶匹配次数。seeds 0～29，各自受真实资金、3/6 手、当前合法 mask 和成交限制。配额概率只依赖剩余配额与已知观察时钟候选数，不使用未来价格、Volume、mask 或止盈标签；成交后扣配额。

不匹配则逐桶报告差异并标记 partial_match，不扩桶、不强制成交、不抹掉失败。随机多 seed 只描述随机采样分布，不是独立市场置信区间；单验证合约不足以宣称普遍优势。

## 证据限制

分钟 OHLC 下全部为冻结协议的模拟成交，并非交易所真实委托成交。人工方向事前可用性、主力退出日事前可知性及独立历史交易所日历尚未证明；研究结论限定为给定方向、观察日历与历史资格退出协议下的择时诊断。

代码位置：`src/gym_trading_env/research/fg_abcd_evaluation.py`；输出完整 CSV 与账户 JSON，不凭摘要隐藏亏损仓位。
