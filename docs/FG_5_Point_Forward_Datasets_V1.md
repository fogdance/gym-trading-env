# FG 前向研究数据集实施与验收 V1

日期：2026-10-10。此阶段生成离线事件研究数据，不启动 DreamerV3，不修改正式 Env、Obs、Action、Reward 或训练配置。

## 配置与划分

统一配置为 `configs/fg_entry_v1/history_study.yaml` 的 `forward_folds` 与 `training_windows_months`。四个截止日：2021-12-31、2022-12-09、2023-12-31、2024-04-30；验证为截止日次日起的后三个自然月。分别使用 12、24、36 个月和自可用数据起的全历史，共 16 组。日期按数据库 trading_date 判定；假期无数据不补造 K 线。

截止日加三个月的具体结束日期为 2022-03-31、2023-03-09、2024-03-31、2024-07-30。验证结束全部早于封存盲测起点 2024-08-20。2026 数据继续封存，不计算研究标签。

## 执行与复用

`fg_history_folds.py` 使用现有数据审计、18 维特征计算及 `run_job` 事件引擎。先按窗口切片，再计算特征和未来首次触达。不同窗口不能直接筛选此前完整合约事件标签。

共享任务必须同时满足：真实合约、角色、实际起止交易日期、行情来源哈希、成交模式、费用、时钟、目标及手数完全相同。只将计划边界裁至该真实合约实际可用日期，不扩大观察范围。验证区间在同一截止日的四个窗口间共享；相同完整合约片段也可共享。16 组产生 105 个独立任务，三种成交模式保留。

`datasets.json` 给出每个窗口的训练及验证任务 ID；ID 对应 `jobs/<id>/events.csv.gz`、`rejected.csv.gz` 和 `complete.json`。这是一组引用式数据集，避免重复复制大文件。研究事件同时包含 LONG / SHORT 独立探针，不能将重叠交易奖励或净收益相加当作真实组合表现。

主力切换只有在真实旧合约最后分钟包含于当前切片时才构成终局；窗口截断仍为右删失、Reward 缺失值，不填失败 0。验证数据不延续训练研究探针的持仓。这个标签划分不改变正式环境的账户延续及退出协议。

每个合约片段的特征从自身起点重新计算，没有提供窗口前 60 根预热数据。因此这些文件是前向标签研究数据，不是可以直接启动 DreamerV3 的新正式数据配置。后续模型实验必须另外确认 Obs 预热、账户跨窗口协议及相同训练预算。

## 命令

在仓库根目录、conda dreamerv3 环境中：

```bash
PYTHONPATH=src python tools/fg_history_study.py fold-plan
PYTHONPATH=src python tools/fg_history_study.py fold-events --workers 4
```

使用 spawn，单进程原生计算线程数为 1；允许 1–8 个工作进程。CPU 仅执行离线事件研究，不进行模型训练。任务目录受文件锁保护；完成后写结果哈希，重复执行校验后复用，损坏的已完成文件会报错，不静默覆盖。

输入、费用、时钟、配置及相关源代码哈希决定输出版本；旧版研究结果保持原目录。所有生成数据留在被忽略的 `artifacts/fg_history_study/v1/forward_folds/`，不提交 Git。

## 验证与限制

回归测试 `test_fg_history_folds.py` 验证跨窗口完全相同切片复用、窗口外主力退出不能构成终局、未来验证期触价不能产生训练奖励以及盲测边界拒绝。既有串行/并行一致、输出哈希及删失测试一起执行。

完成后还需核对：105 个任务全部结束；每个事件决策、入场和观察结束均处于任务区间；成功 Reward 仅使用本区间内实际模拟触达；重复执行全部通过哈希复用。此阶段不比较模型效果，不声称任何窗口最优。
