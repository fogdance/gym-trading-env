# FG 5 点止盈历史行为研究：实施设计 V1

日期：2026-10-10。阶段一实施交付；事件引擎和大规模统计尚未执行。

## 1. 边界与配置

本研究不修改正式 Env、DreamerV3、Obs、Action、Reward，不运行模型训练。研究代码放在 `src/gym_trading_env/research/fg_history_study.py`，入口 `tools/fg_history_study.py`，配置 `configs/fg_entry_v1/history_study.yaml`。配置引用 `fg.yaml` 的固定 345 时钟和成本，不维护第二份方向或手续费配置。所有候选分别研究 LONG 和 SHORT，人工方向不作为事后选择样本的依据。

唯一价格输入为现用 345 分钟主力真实合约导出。旧 375 分钟价格不读入事件引擎。2026 可从 DB 按交易日主力映射追加为盲测；正式训练数据截止仍然不变。输出原始数据、事件标签、统计表、图片放在忽略目录 artifacts；只提交工具、测试、研究配置及文档。

## 2. 审计先于事件计算

已实现 raw CSV 审计，不经过会补零、去重的行情规范化函数。核验文件及主力映射 SHA256、原始必需字段、身份、交易日匹配、OHLC 约束、有限值、Volume/OI、排序、重复、分钟长度、345 时钟、逐合约和逐交易日覆盖。

固定时段为 21:00–23:00、09:00–10:15、10:30–11:30、13:30–15:00，分钟收盘从时段起点加一分钟开始。观测到的时段内部分钟空缺列入质量报告，不能自动解释成真实中断。整段缺失、首尾缺失和节假日无夜盘须独立日历核验，当前报告明确保留这一限制。

原始 OHLC、Volume、OI 存在不等于能证明盘口或真实委托成交。主力资格到期和交易所交割到期分别列名；本研究终局按用户指定的主力切换协议。

## 3. 候选及执行时间

每根完整的一分钟行情结束后产生独立候选，不打乱真实合约内部顺序。仅在下一根符合规则的行情 bob 模拟入场；bob 必须不早于决策 eob，eob-bob 必须为 60 秒，且遵守研究区间、真实合约身份及成交量数量门槛。下一根不可执行时记录拒绝原因，不向未来搜索更有利的开仓价格。

主要口径使用人工确认单侧成本：LONG Open+1，SHORT Open−1，并遵守最小价格变动单位；顺方向目标为成交价 ±5。另输出零价差敏感性结果。入场手数 3；分钟 Volume>=3 仅为模拟可执行门槛，不证明委托流动性。

每个候选是独立探针，不是可同时执行的真实组合，不引入最大持仓时间。休市期间自然分钟继续计时，有效交易根数分别统计。不跨真实合约追踪。

## 4. 两套标签及成交假设

主要标签是 OHLC 首次触价，不能称为真实成交。入场是在下一分钟 Open，所以该执行分钟的 OHLC 触价属于入场后区间假设，分钟内部确切触达时刻仍未知。若开盘跳空已经满足目标可记录 bob；普通 OHLC 首次触价记录时间区间 [bob,eob]，使用 eob 计算保守自然等待时间，另列时间下界。触价 Reward 仅是理论速度指标。

保守对照遵循现有 Env：入场分钟仅 Close 判定退出；后续分钟按退出方向价差调整后需超过目标至少一个 tick；Volume 要覆盖完整三手及该分钟开仓占用；强制风控终局优先于未知先后顺序的 TP。先通过孤立单笔 Env 回放核对，再赋予对照标签。对照需要账户状态的分支不能仅凭 OHLC 宣称完全等同 Env。

不得使用入场之前决策分钟的 High/Low，不得因触价直接赋予正式训练 Reward。专项测试自然 1、2、5 分钟盈利、入场分钟先后不明、停盘、零时长、容量不足及换主力风险优先。

## 5. 状态、删失及 MAE

状态至少分为成功触价、主力资格到期未成功、数据缺记录删失、研究窗口删失、不可执行候选。主力切换前最后可执行旧合约价格终局，不读取新合约价格。没有充分到期证据的文件末尾是删失。

完整三手模拟成功才计算理论 `60/(60+T)`；确认终局未成功为 0；右删失 Reward 为缺失值，不能填 0。所有结果保存 censor_reason、terminal_reason、观察截止时间和来源哈希。

历史 23:00 后被政策截断的价格不可用于首次触价。若跟踪跨过已知被截断交易区间，标记不可观测，并采用保守删失，不能假定首次触价只会出现在保留时钟内。可以读取截断审计的时间身份信息，但不能使用被删掉的价格完成事件。输出覆盖损失比例，不能隐藏早期夜盘删失偏差。

MAE 用实际入场价到最不利价格的点数，LONG 为 entry−Low，SHORT 为 High−entry，至少为 0。首次触价分钟内未知极值先后：同时给出不含该根的下界及包含该根的上界，不把上界冒充成交前真实 MAE。删失样本 MAE 仅截至可观测区间。

必需列：contract、trading_date、entry_timestamp、direction、entry_price、tp_price、first_touch_timestamp、duration_minutes、duration_trading_bars、MAE、completion_status、reward。补充 decision_timestamp、touch_time_lower/upper、MAE_lower/upper、entry_session、role、execution_assumption、观察截止、删失/终局原因及来源哈希。无成交候选单独保存，交易成功率分母不得混入拒绝开仓。

## 6. 泄漏边界

按 trading_date 冻结时间分区：训练截至 2022-12-09；开发验证 2022-12-12 至 2024-08-19；最终前向盲测 2024-08-20 至 2026-10-09。节假日边界实际按存在的交易日取交集。盲测允许质量审计，禁止读取事件结果选择窗口。

先切片每个区间的原始价格，再构造首次触达查询索引。训练事件标签不能读取验证价格；任何历史实验 fold 和窗口也要先切片再计算终局/删失。不能先在全历史找 TP 后按 entry 日期分组。跨区间仍持仓必须记录窗口删失。不同合约同一日历时期不能随机拆到前向两侧。

FG605 的 2025、2026 原始片段可以按真实合约合并，但在事件查询时仍须遵守 role/fold 截止；不能把年度文件边界误认为合约到期。

## 7. 特征因果与条件分析

直接复用已有 18 个输出特征，不增加指标。obs_V_t 固定为 `tanh(log1p(clip(V,0,None))/5)`。前缀检查将完整样本与逐步前缀比较，并修改未来价格和成交量验证过去输出不变。测试范围和异常数据限制必须写入报告，不宣称有限检查证明全部可能输入。

条件分箱仅用早期开发数据冻结。先比较所有 18 个特征的年度分布，再以既有波动、漂移符号、日/夜盘组成可解释主分组，方向及交割月分别报告。使用固定参考分组权重标准化，区分整体波动变化、状态组成变化与组内止盈变化。稀疏单元不作稳定结论；不冒称三项分组已控制完整 18 维状态。不能由条件差异直接认定主力控盘机制变化。

## 8. 统计与不确定性

按年、季度、交割月、方向、日/夜盘及波动环境统计样本数、独立交易日数、合约数、成功/终局/删失数、时间及 MAE 分布、理论 Reward 分布。5/15/60 分钟按自然时间计算；一/五交易日按入场日和第五个实际交易日收盘定义，分别显示入场时段，不能以 345/1725 根代替交易日。

右删失不能填失败。报告已观测成功率界限及带终局竞争风险的累计触达概率，说明删失非随机的限制。缺少足够随访的样本不得无提示进入固定期限比例。

置信区间按合约聚类 bootstrap 1000 次、seed=0，另以 5/20 交易日块作敏感性；抽样只用于聚合，不重新拼接价格序列。合约少于 6 的组标记推断不足，不能以逐分钟独立二项区间替代。多组比较以描述为主，避免凭平均值断言规律改变。

## 9. 算法、测试和交付顺序

首次触达与 MAE 使用按真实合约、区间、模式建立的区间最大/最小查询，避免逐候选扫描未来导致 O(n²)。小规模确定性数据先与朴素扫描比对。缺记录/已截断区间建立截止屏障，不能越过屏障恢复跟踪同一事件。

第一提交交付本设计、数据报告、可复现审计 CLI、配置及针对性测试，当前不计算大规模事件。

下一提交实现事件引擎，覆盖 1/2/5 分钟、同分钟触价/保守不成交、休市自然时间、部分/无可用成交量、零时长、主力切换、窗口与缺记录删失、MAE 边界、分区未来价格防护，以及 Env 单探针一致性。

确定性回归通过后才执行开发区事件和统计。每合约/区间/模式独立输出 CSV.gz，汇总 CSV/JSON、PNG/SVG 图表；当前环境无 pyarrow，默认不安装依赖。封存盲测事件和结果，直到训练窗口选择规则冻结再独立运行。

最终六项交付：质量报告、逐候选研究数据集、分组统计、市场变化图表、条件分析、12/24/36 个月及全历史窗口实验建议。窗口在同一历史截止上比较，有足够历史后再滚动。统计事实、模拟假设和未验证模型能力分别标记；本研究不能证明 DreamerV3 学会择时，也不会自动启动训练。
